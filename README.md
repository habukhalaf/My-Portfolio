# Haneen Abu-Khalaf - Design Portfolio

[![Website Live](https://img.shields.io/badge/Website-Live-brightgreen.svg)](https://habukhalaf.com)

Welcome to the repository for my design portfolio. As a Data Science and Artificial Intelligence student at Princess Sumaya University for Technology, this custom-built, fully responsive website showcases my technical and creative work spanning data science, cybersecurity media leadership, and visual design.

## Tech Stack
- **Frontend:** HTML5, CSS3 (Mobile-Responsive Flexbox)
- **Hosting:** GitHub Pages
- **Domain:** Custom domain secured with HTTPS

## Directory Structure
- `/images/` - Consolidated image assets, icons, and project thumbnails.
- `/projects/` - Individual HTML files for specific project showcases (e.g., CTF events, design work).
- `/static/` - Global stylesheets, including mobile media queries.
- `index.html` - Main landing page.
- `about.html` - Personal background and contact information.
- `resume.pdf` - Professional resume.

## Local Setup
To view this project locally, simply clone or download the repository and open `index.html` in any modern web browser. No local server or build process is required.
